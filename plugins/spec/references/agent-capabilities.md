# Agent Capabilities

**Purpose:** The dated list of platform capabilities an agent in a spec may depend on. Agents Level 2 element E cites a capability name from the first column, never a provider, so a spec stays true when providers change. The Providers column is a snapshot for the engineer who maps the spec to a stack; refresh it monthly, or when a Level 2 run needs a capability that is not here.

**Refreshed:** 2026-10-21 by the owner and Claude, from web search on that date. Providers are Reported from secondary coverage unless marked Verified against a vendor page; dates are as the sources gave them. Sources at the end.

| Capability | What the agent can do | Providers (snapshot, 2026-10) | Spec notes |
|---|---|---|---|
| user turn | Run when a person sends a message | Every chat host and SDK | Default trigger; no dependency line needed |
| scheduled run | Wake on a clock without a user present | Claude Managed Agents scheduled deployments (cron); Claude Code routines; OpenAI scheduled tasks; cron, Prefect, Temporal on the product's own host | State who owns the clock: the AI platform or the product |
| background run | Run for minutes to hours, detached from a session, report when done | Claude Code background agents and cloud sessions; Claude Managed Agents (public beta 2026-04); OpenAI Dots, always-on agents with their own cloud computer (DevDay 2026-09-29); Codex cloud; Gemini agent, persistent in the cloud (2026-10-08) | Needs a kill switch and a status surface |
| sub-agents | Spawn and wait on child agents inside one run | Claude Agent SDK and Agent Teams (research preview 2026-02); Claude Code dynamic workflows (2026-05); OpenAI Agents SDK; ChatGPT GPT-6 Pro parallel agents (2026-10-16); Gemini agent sub-agents; Microsoft Agent Framework; LangGraph | Handoff pattern goes in D.1, not here |
| agent-to-agent | Talk to an agent another party runs, over a protocol | A2A v1.0 (2026-03, v1.0.1 2026-05), governed with MCP under the Agentic AI Foundation since 2026-08; IBM ACP merged into A2A 2025-08 | Each remote agent is an Interfaces row with an owner |
| MCP client | Call tools a product exposes over MCP | Claude, ChatGPT, Cursor, VS Code, Claude Code, Slackbot (2026-03), Gemini agent | The product side is an Interfaces tool row |
| MCP server | Expose the product's tools to an external host | Any product with an MCP endpoint; the OMS example `/mcp` (Verified). MCP spec 2026-07-28: stateless core, Tasks for long-running calls, Skills over MCP, MCP Apps for inline UI; roots, sampling, logging deprecated | Surface is `host chat` in Product Surface; a tool that takes minutes is an MCP Task |
| host UI | Render interactive UI inside the host chat, not only text | MCP Apps (spec 2026-07); ChatGPT plugins sidebar, panels, and file viewers (2026-09); Claude artifacts | Product Surface host chat gains controls when this is used; say so in D.1 constraints |
| web search | Fetch and read public pages | Claude, OpenAI, Gemini, Exa, Tavily | Result is a Knowledge raw origin `agent web search` |
| file system | Read and write local files on the user's machine | Claude Code, Codex CLI, Gemini CLI, VS Code agents, OpenAI Agents SDK model-native harness (2026-04) | Local folders are Knowledge raw corpora, store `local file system` |
| code execution | Run code in a sandbox | Claude code execution; OpenAI Agents SDK native sandbox (2026-04); E2B; product sandbox | Risk rating on the Interfaces tool row |
| computer use | Drive a browser or desktop | Claude computer-use agent, research preview 2026-03, via Claude Desktop Cowork; Claude in Chrome; OpenAI Agents API computer use and Dots browsers (2026-09); Browser Use | T2 minimum until Evaluation says otherwise |
| voice | Listen and speak in real time | OpenAI Realtime API (`gpt-realtime` GA, MCP and SIP support); ElevenLabs Agents (Expressive Mode 2026-02, Flows 2026-03); Twilio ConversationRelay; Vapi; Retell; LiveKit Agents; Pipecat; Gemini Live; Codex CLI voice input | Surface type `message` or `mobile app` with constraint: no tables; per-minute cost is an NFR row |
| messaging channel | Send and receive on Slack, Teams, SMS, WhatsApp, iMessage | Slackbot as agent, GA 2026-01-13, MCP client 2026-03, Slack Code for coding agents 2026-08-20; Microsoft Teams agents; Twilio; WhatsApp Business API; Gemini agent in Slack and Microsoft 365 | Surface type `message (channel)`; capability line states read-only or not |
| memory | Keep facts across runs | Claude memory and Dreaming, session review for self-improvement (research preview 2026); OpenAI memory and Dots preference learning; product-owned store | The entity holding it is a Data Model row; retention in B.2 |
| memory consolidation | Review and tidy stored memories between sessions: merge duplicates, drop contradicted facts, absolute dates, cap the index | Claude Code Auto Dream and `/dream` (2026-03, feature-flagged; after 24 h and 5 sessions per secondary sources); Anthropic Managed Agents Dreaming (research preview 2026-05); ChatGPT Dreaming synthesis after conversations (2026-06); Letta sleep-time compute; Mem0 recency decay | Memory Level 2 B.2; the run is an Autonomy action; user should see the diff |
| agent identity | Act under its own account, not the user's, and prove it per hop | Gemini agent with its own Workspace account and email (2026-10); Microsoft Entra Agent ID (GA 2026); service principals on the product's own identity provider; MCP authorization spec 2026-07-28: OAuth 2.1, protected resource metadata (RFC 9728) and resource indicators (RFC 8707) required, Client ID Metadata Documents replace dynamic registration, token passthrough forbidden, step-up on insufficient scope; NIST AI Agent Standards Initiative (2026-02); delegation through sub-agents still unsettled (OIDC-A, CIBA drafts) | Data Access row for the agent as principal, Identity line per principal and one chain line per path; Autonomy owner named |
| long context | Load a distilled corpus whole | Models at 200k tokens and above; context compaction in OpenAI Agents API (2026-09) | Knowledge Level 2 C.2 sets the ceiling per task |
| structured output | Return a typed object the product can parse | Every major API; tool-call schemas; OpenAI Decisions API for picking from a fixed set (limited preview) | Interfaces Level 2 contract card names the schema |
| artifacts | Produce a document, page, or file the user keeps | Claude artifacts; ChatGPT canvas; product documents | Surface type `document` |

**Refresh rule:** Add a row when a Level 2 run needs a capability absent here; never delete a row, mark it `retired` with the date. Provider names change freely; capability names change only with a Catalog edit, because skills cite them.
